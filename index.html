Security Model & Architecture

1. Authenticated Encryption (AEAD)

This tool utilizes XChaCha20-Poly1305 (IETF AEAD) with an extended 192-bit random nonce. It provides both confidentiality and cryptographic integrity verification. Any alteration or tampering of the ciphertext is detected immediately by the Poly1305 MAC tag prior to releasing plaintext.

2. Memory-Hard Key Derivation (Argon2id)

Passwords are transformed into a 256-bit encryption key using Argon2id v1.3, the winner of the Password Hashing Competition. Argon2id provides state-of-the-art resistance against GPU/ASIC brute-force attacks and side-channel timing attacks by requiring substantial memory allocations (64 MiB) during derivation.

3. Random Salt & Nonce Freshness

A fresh 128-bit cryptographic salt is generated for every encryption operation, preventing precomputed dictionary or rainbow-table attacks. A fresh 192-bit nonce eliminates the risk of nonce-reuse collisions even across millions of operations.

4. Zero Server Storage & Privacy Guarantees

  • Local Execution: All encryption and decryption routines occur in your browser's local WebAssembly/JavaScript environment.
  • No Transmission: Plaintext, passwords, keys, salts, and nonces are never sent over any network, backend API, analytics platform, or telemetry service.
  • Ephemeral Memory: Derived keys are zeroized in memory immediately after cryptographic operations. No sensitive data is saved to localStorage, sessionStorage, cookies, or IndexedDB.
  • Zero Recovery: No backdoor or password recovery exists. Losing your password means the data is permanently unrecoverable.
"With a strong password and a correct implementation, recovering the plaintext by breaking the cryptographic primitives is designed to be computationally infeasible with currently known practical attacks."

5. Binary Envelope Specification

Output ciphertexts are packaged in a compact, portable binary structure encoded in RFC 4648 Base64url:

  • Byte 0: Protocol Version (0x01)
  • Byte 1: Cipher Suite ID (0x01 = Argon2id + XChaCha20-Poly1305)
  • Bytes 2–5: Argon2id OpsLimit (uint32 big-endian)
  • Bytes 6–9: Argon2id MemLimit in KiB (uint32 big-endian)
  • Bytes 10–25: 16-byte Cryptographic Salt
  • Bytes 26–49: 24-byte Extended Nonce
  • Bytes 50+: Ciphertext body with appended 16-byte Poly1305 MAC tag
